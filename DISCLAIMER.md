# Intended Use and Limitations

**SILENT MEDIC is a reference and decision-support aid. It is not a medical device.**

- This software has **not** been reviewed, cleared, or approved by the U.S. Food and Drug
  Administration or any other regulatory authority, and it is not intended to diagnose,
  treat, cure, or prevent any disease.
- Output is generated from a static rule base and a curated drug reference. It does not
  account for the full clinical picture, patient-specific contraindications, allergies,
  drug interactions beyond those encoded, local formulary, or command medical direction.
- **Clinical judgment governs.** Any recommendation produced by this tool must be verified
  against current authoritative guidelines, local protocol, and the treating provider's
  own assessment before it is acted on.
- Dosing, route, and timing shown here are drawn from published guidelines current as of
  the stated build date. Guidelines change. Verify against the current published version
  of the TCCC Guidelines, the Joint Trauma System Clinical Practice Guidelines, and
  applicable prescribing information.
- Some entries describe **dual-use** or off-label applications reported in the prolonged
  field care literature. These are provided for situational awareness in resource-limited
  settings and are explicitly not a recommendation for routine practice.
- The application stores query history in browser local storage on the device for personal
  convenience only. **It is not a medical record** and must not be used as one. It is not
  designed for, and must not be used to store, protected health information.

Use of this software is at the user's own risk. No warranty, express or implied, is made
as to accuracy, completeness, or fitness for any particular purpose.
